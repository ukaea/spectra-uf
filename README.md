# SPECTRA-UF

Benchmarking of the methods were undertaken using synthetic data sets based on activation foil detectors and spectra found in a variety of fusion environments. Any use of SPECTRA-UF should reference the paper 'The development, testing and comparison of unfolding methods in SPECTRA-UF for neutron spectrometry' (https://doi.org/10.1016/j.fusengdes.2020.112038).

## Installation

The code can be installed by pulling the master branch from the CCFE git repository 

```bash
git clone git@git.ccfe.ac.uk:rworrall/spectra-uf.git
```

The package can be installed in editable mode via the following:

```python
pyhton -m pip install -e .
```
